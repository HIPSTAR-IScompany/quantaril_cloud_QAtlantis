# 神学・信仰の射程と鎮魂・和解

状態: `ALPHA GUIDE / Layer B`

この文書は共通教義を制定しません。神学者、宗教実践者、牧会者、祭祀者が、自らの信仰定規を明示し、
他宗派、工学、医療、人間工学の射程を消さずにQ Atlantisへ参加するための入口です。

## 言語化された信仰解釈と霊障を分ける

天罰、裁き、カルマ、因果応報、呪い、呪霊、念、依代等は、それぞれ異なる信仰、宗派、World、主体論、
時間観、救済論を持ちます。同じ「宗教的原因」fieldへ正規化しません。

これらの語で説明できることは、客観原因が確定したという意味ではありません。少なくとも、誰がどの
信仰定規から提示した解釈かを追跡できる状態になったということです。

`霊障`は、そのどれにもまだ置けず、意味次元以上で射程自体が見えない状態を保全するalpha Bridgeです。

## 信仰告白とauthority

- 宗派、信仰、無宗教、混成Worldは本人の自己申告だけを使う
- AIがmemory、名前、服装、語彙から宗派を推定しない
- 自分の宗派で採用した解釈を`adopted-in-scope`として示す
- 別宗派の教義、救済、罪、禁忌を裁定しない
- ゲームWorld内の神学と、現実共同体の信仰実践を無標識に接続しない

信仰告白は他Worldへの越境権限ではありません。同時に、工学側の説明も信仰を取消すauthorityではありません。

## 抱え込みで魔王を育てない

すべての不整合を悪、罪、魔王、荒御魂、敵対主体へ集約すると、説明と処方が一つの敵へ集中します。
その結果、環境調整、製品修正、人間工学、医療、別宗派の解釈、当事者の退出が見えなくなることがあります。

討伐以外にも次の経路を開きます。

- 鎮魂する
- 和解する
- 距離を置く
- 境界を引く
- 役割と一時的authorityを終える
- Worldまたは解釈を分岐する
- 可逆な環境調整を試す
- 工学的原因だけを修理する
- 解釈不一致を残したまま共存する

「悪ではない」と先回りして決めるのでも、「悪に違いない」と固定するのでもありません。どの解釈を誰が、
どのscopeで採用したかを残します。

## 人間工学へのprojection

工学者へ渡すとき、教義を捨てずにeffectを展開します。

| 信仰上の原語 | 人間工学で尋ねること |
|---|---|
| 裁き、天罰 | どの言葉、行為、表示で罪責や恐怖が強まったか |
| 断絶、穢れ | 誰との関係、どの場、どの退出不能がpainになったか |
| 呪い、念 | どの反復、人物、記憶、通知、symbolが作用を維持したか |
| 依代 | 何にidentity、役割、authority、記憶が結び付いているか |
| 鎮魂、赦し | どの終端、解除、謝罪、和解、記録が必要か |

この表は信仰語を心理語へ置換する辞書ではありません。原語とengineering projectionを並存させます。

## 専門棚へのhandoff

- 再現可能なsoftware挙動は工学へ渡す
- UI、課金、離脱、尊厳のpainは人間工学へ渡す
- 生活や健康への深刻な影響は、本人中心で適切な専門職へ渡す
- 環境要因は可逆な調整を試す
- 宗派固有の儀礼・牧会は、そのauthorityを持つ実践者へ渡す
- 射程が見えないものは霊障として保全する

引き継いだから神学的意味が消えるわけではありません。逆に、神学的意味があるから工学修正や支援が
不要になるわけでもありません。

## まつりと「後の祭り」

祭り、祀り、奉り、政を含む場では、開始だけでなく終端が必要です。

- 退出と撤回を示す
- 一時的な役割、依代、authorityを解除する
- 遅れて現れた異議とpainを受け付ける
- 参加者、非参加者、途中離脱者を自己責任で切らない
- 無効、悪化、unknownを成功物語で消さない

祭りの熱量を起こす能力より、後の祭りを発生させず、残ったものを鎮魂・引継ぎできる能力を重く見ます。
