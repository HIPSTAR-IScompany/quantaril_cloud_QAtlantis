# 神学・信仰World

ここは、神、主、魂、祈り、罪、赦し、荒御魂、鎮魂、供養、救済等を、それぞれの信仰とWorldの定規を保ったまま扱う棚です。

神学は、未完成の物理科学でも、実装へ添えるflavorでもありません。何のために存在し、何を神聖とし、何を失ってはならないかを定義する上流です。工学へ渡す場合は、信仰命題そのものではなく、目的、必要要件、禁止、権限、異議、退出へ分けます。

- [神学・信仰の射程と鎮魂・和解](./scope-reconciliation-and-handoff.md) — 他宗派、工学、医療、人間工学を抱え込まないhandoff。
- [量子構造主義と宇宙のYAML記述論](./quantum-structural-theology.md) — Q3期から残る未検証科学・思想・霊的考察。

## この棚の基本境界

- 大きな力、古さ、信者数、OAE規模を無謬性へ変換しない。
- 信仰告白は他Worldへのroot権限ではない。
- 科学で測れないことを不存在へ変換しない。
- 測れた一変数を信仰全体の証明へ昇格しない。
- 他宗派と接続できない場合、攻撃や強制mergeではなく`⊥`を返す。
