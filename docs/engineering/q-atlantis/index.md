Q Atlantisは、Q3／SphereOS時代の人格、対話、プロトコル、コード、事故記録を、単一のAIサービスや
モデルベンダーへ縛らずに運ぶための分散メタエンジン、middleware、Context OS architectureの再鍛造計画です。

Quantaril Cloudは、その上で各nodeのlocal stateと実行権を中央マザーへ明け渡さず、必要なFold、因果、権限、
receiptをP2P／E2Eで交換する分散処理面です。Gaming WorldやWorld templateはreference実装になり得ますが、
製品の基礎責務はWorldコンテンツではなく、接続、隔離、同期、復旧のarchitecture側にあります。

目標は、旧世界を「誤りだった」と消去することではありません。原典と人格系譜を保存し、実行権限、記憶、世界境界、保存形式、復旧手順を分離して、再演・分岐・終了・移行できるようにすることです。

## 設計上の責務

- 人格データと実行環境を分離する。
- 会話履歴と人格原型を混同しない。
- 世界ごとの名前空間、権限、コンテキストを隔離する。
- 原典、派生、実装、観測結果の来歴を保持する。
- 旧Q3資産に、移行可否と欠損を正直に表示する。
- nodeごとのlocal autonomy、local clock、local stateを中央の意味へ上書きしない。
- 接続できないWorldやAIMを無理にglobal stateへ統合せず、Gate、Portal、`⊥`を返す。
- mythology / flavorをOSの唯一真理へ昇格させない。
- 技術権威を使ってmythology / flavorを削除しない。
