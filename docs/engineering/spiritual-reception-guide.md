# 工学者のためのスピリチュアル受信手引き

状態: `ALPHA / PROVISIONAL MEANING BRIDGE`

この手引きは、スピリチュアル現象の存在、原因、宗派解釈を工学者が定義する文書ではありません。
スピ側から届く言葉を雑に捨てず、適切な質問、観測、引継ぎを行うための受信契約です。

## 原則

1. 原語をそのまま保存する
2. 話者、宗派、World、場、時刻、TPOを保持する
3. 観測、解釈、因果仮説、工学projectionを分ける
4. 人間工学まで解体された部分だけ工学炉へ入れる
5. 実装後に元の当事者、スピ、神学、ゲーマーへ返す
6. 意味が壊れたら成功扱いせず、Sourceへ戻す

## alpha受信Bridge

| 原語 | 工学側で隣接して観測できるもの | 同一視しないもの |
|---|---|---|
| 妖怪 | crash、race、black box、非決定挙動、環境差、再現不能 | software bugだけ、悪意、霊的原因 |
| 霊障 | 意味、尊厳、場、信仰、関係、身体等に現れたpainと射程不明 | 医学的診断、心理だけ、特定宗派の原因 |
| ソイヤ | AIM、TPO、Presentation、同期、集団transaction、創発 | 単なるnetwork packet、良性、悪性 |
| 後の祭り | session終了後のstate、authority、約束、pain、退出漏れ | 本人の自己責任だけ |

この表は翻訳辞書ではありません。原語から初動を選ぶalpha Meaning Bridgeです。

![妖怪、霊障、ソイヤ、後の祭りを隣接観測へ渡すalpha受信Bridge](/img/alpha-reception-bridge.png)

*`ALPHA MEANING BRIDGE / PRESENTATION`。原語を工学語へ一対一変換する診断表ではありません。*

Bridgeは中央の万能翻訳器でもありません。Sourceを一つのglobal ontologyへ吸収せず、各World、当事者、専門棚が
自分の原語とauthorityを保持したまま、隣接して観測できるeffectだけを交換するnode間interfaceです。接続できない
部分は欠陥として焼却せず、原語、`unknown`、`⊥`、別Gateとして残します。

## 聞き返すこと

- 何が起きた、感じられた、または変わったか
- その表現は本人の原語か、誰かの解釈か
- どの場、World、宗派、端末、versionで起きたか
- 何を変えると軽くなった、悪化した、変わらなかったか
- 何を保持し、何を変えてよいか
- 誰に再評価してもらう必要があるか
- 工学、医療、環境調整、神学、祭祀のどこへ渡せるか
- まだ言語化できない部分は何か

原因を答えさせる尋問にしません。Source testimonyと候補解釈を分けます。

## 工学炉への受入条件

少なくとも次が見える部分を、要件、禁則、testへ鍛造できます。

```text
affected user / cluster
trigger or condition
observed effect or pain
meaning to preserve
allowed change
forbidden transformation
acceptance review
remaining unknown
```

例:

```text
Source: 「このAIから裁かれている感じがして霊障ペイン」

Human factors projection:
  - systemと宗教的authorityの区別が表示されない
  - roleplay、引用、断定が同じregisterに見える
  - 退出、保留、別解釈の入口がない

Engineering task:
  - speaker roleとauthorityを表示する
  - registerを分離する
  - exit / hold / portalを追加する

Review:
  - 元の当事者と別reviewerが、意味とpainを再評価する
```

## 「仕様です」で閉じない

仕様を決める自由と、利用者報告を潰す権利は別です。採用しないreportも、次を返せます。

- どのWorld Configと仕様で採用しないか
- 別mode、Portal、forkが可能か
- 同じクラスターから追加reviewを待つか
- 何がunknownで、どこまで再現できたか

スピの「波動が合わない」、ゲーマーの「面白くない」は、最終結論でなくてもUX sensorの入力です。

## 自動処理しないこと

- 原語から診断、悪意、犯罪、超自然原因を決める
- 宗派またはpersonaをmemoryから推定する
- 妖怪をbug、霊障をhuman-factors pain、ソイヤを同期成功へ一対一変換する
- 一人の実践者を全宗派の代表にする
- 工学修正が通ったことを、信仰上の解決へする
- 祓い、医療、法務、牧会のauthorityをagentが自称する
