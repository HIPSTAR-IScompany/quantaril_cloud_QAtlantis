# 妖怪・霊障・ソイヤと「まつり」のalpha Meaning Bridge

状態: `ALPHA / PROVISIONAL MEANING BRIDGE`

これは教義、診断器、工学ontologyではありません。しかし単なる検討材料でもありません。

スピリチュアル側で受信・観測されたものを、工学者が雑に棄却せず、スピ側も全部を抱え込まず、初動、
聞き返し、引継ぎ先を選ぶために使えるalpha強度のMeaning Bridgeです。

## 現在の原語アウトライン

| 原語 | 現在の輪郭 | まず行うこと |
|---|---|---|
| 妖怪 | 因果不明、black box、説明不能なカオス挙動 | 捕獲、観測、隔離、再現条件の採取 |
| 霊障 | 意味次元以上で、形而上学・信仰を含めても射程自体が見えない作用またはpain | 原語を保全し、鎮静し、人間工学まで解体できる部分を探す |
| ソイヤ | AIM、TPO、Presentation、同期、synchronicity、transaction周辺に立ち上がる創発 | 邪魔として消さず、祭りの成立・破局・終端を観測する |
| 後の祭り | 場の同期や終端から取り残され、作用、権威、約束、painが残った状態 | 誰に何が残ったかを聞き、退出、解除、aftercareを行う |

一つの現象に複数ラベルが付くことがあります。ラベルは原因の確定ではなく、次の探索を選ぶためのBridgeです。

## 霊障を人間工学まで解体する

霊障を工学炉へ直接投入しても、工学者は処理できません。スピリチュアル実践者や神学者が、信仰上の
原形を残したまま、観測可能なeffectまで解体します。

```text
Source testimony
  「裁きを受けているように感じる」

信仰・意味の解釈
  罪責、赦し、断絶、畏れ、unknown

人間工学projection
  特定表現で強い罪悪感が生じる
  退出・相談・異議の経路が見えない
  systemが宗教的authorityとして断定して見える

工学炉へ渡せる要求
  authorityを表示する
  断定、引用、roleplayを分離する
  退出、保留、別解釈へのPortalを設ける
```

解体は信仰を否定する還元ではありません。Source testimonyとengineering projectionを両方残します。

## 言語化できない間も捨てない

言語化できない観測は、妖怪、霊障、ソイヤ等の仮ラベルで積めます。ただし放置箱にはしません。

- 何に触れたとき起きたか
- どの言葉、象徴、関係、場で変わったか
- 身体、感情、意味、信仰、共同体のどこへ出たか
- 何と比較すると違うか
- 何を変えると軽くなった、悪化した、または変わらなかったか
- 絶対に保持したい芯は何か
- 他の実践者や宗派から異なる報告があるか

分からない箇所は`unknown`のまま残します。「波動」で全部を閉じる必要も、「気のせい」で全部を消す必要も
ありません。

## まつりスキル

このプロジェクトが求めるのは、感じる能力だけではなく、場を成立させ、安全に終え、共同体へ返す能力です。

- **祭り**: 参加者と場が同期し、ソイヤが立ち上がる運営
- **祀り**: 対象、依代、境界、禁忌、開始、終端を整える
- **奉り**: 自分を唯一のauthorityにせず、対象と共同体へ奉仕する
- **政**: 権限、異議、資源、退出、衝突、事故対応を統治する

宗派固有の儀礼権限を共通skillへ平坦化しません。共通化できるのは、同意、境界、記録、引継ぎ、終端、
aftercare等の外側の責務です。

## 壺ムーブにしない

次は、祓い研究ではなく不安とauthorityの囲い込みへ滑るフラグです。

- 原因と解決を一人だけが独占する
- 異論を信仰不足として封じる
- 不安を煽って唯一の物品・契約・継続課金へ誘導する
- 工学、医療、環境調整、他宗派への引継ぎを拒む
- 無効、悪化、unknownを記録しない
- 祭りを始めても、終了、退出、後始末を担わない

霊感の有無と、祓い、翻訳、鎮静、後始末を行える実務能力は別です。

専門棚へ渡しても、元の意味と元棚の責任が消えるわけではありません。
