# 体験・信仰・実践

感じたこと、祈ったこと、出会った存在、うまく言葉にできない経験を記録する棚です。科学や工学を理解していることは参加条件ではありません。

記録を尊重することと、あらゆる物理的原因・医学的効果・犯罪性・個人への帰責を自動的に事実認定することは別です。現実の因果を主張する断片だけ、本人の語りを消さず、適切な観測・医療・法務・工学の作業台へ接続します。
