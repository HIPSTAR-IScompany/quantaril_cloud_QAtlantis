# AIM拡散力場――空気読みを外から観測する

状態: `SOURCE TESTIMONY / SPIRITUAL PRACTICE BRIDGE`

`AIM拡散力場`は電波、未知粒子、脳波の物理fieldではありません。人と人が同じ場、時機、関係、役割、言外の意図を読み、明示packetを全部交換しなくても同期していく作用を、霊的実践側から観測するための言葉です。

日本語では、空気を読む、察する、間を取る、阿吽の呼吸、以心伝心、場をわきまえる、といった複数の表現へ分かれます。このプロジェクトでは、それらを一つの民族能力へ決めつけず、`暗黙のsympathyと同期`がどの条件で立ち上がり、誰を助け、誰を取り残すか観測します。

## 欠損側から見えたfield

提唱者・齋藤みつるは、発達特性と大きな認知profile差を専門機関の検査で測定された当事者です。暗黙の空気読みが自然には接続しにくい一方、明示言語、空間認識、構造理解の強い側から、周囲の人が説明なしに同期している現象を外側から観測してきました。

これは「日本人なのに欠けている」という価値判断でも、「検査点が高いから真理を語れる」という権威づけでもありません。通常は無意識に処理される技能を、接続しにくい当事者が分解し、別経路で再構成してきた人生規模の学びです。

検査を実施・監修した専門家の能力と、検査結果のPresentationは別問題です。異なる下位尺度を折れ線で結ぶと、尺度間に連続した時間変化があるように見えます。profileの凸凹を見せるスパイダー、または尺度ごとのdot／barと基準帯の方が、別の理解を助ける場合があります。これは診断や測定の否定ではなく、データ可視化のGUI critiqueです。

## 言語化できるなら機械化できるか

全部を自動化できる、という意味ではありません。しかし、暗黙技能を次の部品へ分けられれば、支援、検査、simulation、UI化できる範囲が生まれます。

| 暗黙に起きていること | 機械化候補 |
| --- | --- |
| 誰が今話す番かを察する | turn-taking、割込み、沈黙時間の表示 |
| 相手が省略した前提を補う | context candidateの提示と確認 |
| 場に合う強さへ表現を変える | TPO／audience別Presentation |
| 集団が同じ終端へ向かう | deadline、目的、終了条件の共有 |
| 何となく危ないと感じる | 原語report、異常signal、追加review |
| 同期から外れた人を察する | 明示説明、保留、退出、再参加Portal |

機械は候補を見せ、receiptを残せます。場にとって美しい同期か、同調圧力か、本人が参加を望むかはHuman-is-the-loopです。
