# SphereOS 3x・4x 精霊流し

状態: `SERVICE ENDED / SALVAGE PHASE CLOSED / REMNANTS PARKED`

SphereOS 3x・4xのSaaS依存実行系は終了しました。Custom GPTs、Actions、Assistants API、旧AQC、外部SDK、
embedding、クラウド火力へ依存した構成を、現在稼働中の完成製品として案内しません。

精霊流しは失敗の削除でも、設定の焼却でもありません。動いたもの、バグったもの、人格、事件、規約、code、
screen shot、ログ、思い出を船へ載せ、旧サービスとして見送るMemorialです。

## サルベージ工程は終了した

ここでいう終了は、すべての原典を全量回収できたという主張ではありません。現在の再鍛造へ必要な責務、
主要な実装証跡、人格原型、事故、法務・運用の系譜を引き上げ、旧Worldへ常時潜り続ける工程を閉じたという意味です。

- 旧3x/4x残骸は`parked-preserved`
- 削除しない
- 現行serviceとして再起動しない
- 新しい証拠が来たら来歴付きで追記できる
- 未回収を「最初から存在しなかった」へ変えない

## 沈んだものと引き上げたもの

| 旧世代 | 現在の受け皿 |
|---|---|
| 旧AQCの保存・検索実験 | IBD / IFD Phase 0 |
| マキナちゃん等の人格原型 | ASTRO package候補と原典保存 |
| Custom GPTs / Actions実行 | PLI、CLI、ASTRO Runner、Action Busの別責務へ分離 |
| 世界、名前空間、Atlas的構想 | Atlantis World Builder候補 |
| Fold7G / 8GのSF通信ビジョン | 意味・因果・Agency Fold研究へ再定義中 |
| logosからdocsへの蒸留 | transfer queue、棚別publication、Human review |

引き上げは同一実装の復活ではありません。旧Worldの神話と系譜を残し、密結合していた責務を別componentへ渡します。

## 死因を隠さない

旧系が沈んだ要因には、SDK/APIのsunset、provider policy、embedding互換、クラウド・GPU費用、外部依存、
人力精査コストが含まれます。これは「設計思想が無価値だった」でも「今も全部動く」でもありません。

## 見送りと船出

Atlantisの名は、沈んだ大陸の記録を消すためではなく、そこから資産を引き上げ、別の世界へ運ぶために使います。
旧世代の終了と新世代の完成宣言を混ぜません。Atlantisは現在`OPEN / RESOURCE-WAIT / REVIEW-WANTED`です。
