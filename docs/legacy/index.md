# Q3 / SphereOS Memorial

Q3／SphereOS 3x・4xは、Q Atlantisへ続く実験世代です。バグ、外部サービス依存、未検証の記述、当時の強い言い切りを含みますが、現在の言葉へ黙って書き換えず、その時代の人格と世界を伝える資料として保存します。

Memorialは墓標だけではありません。再実装できる構造、救出すべき人格、再発防止に必要な事故記録、現在へ持ち越さない契約を見分けるためのサルベージ海域です。

## 読むときの状態

- 文書全体: `LEGACY-PROTOTYPE / HISTORICAL`
- Q3実装: `BUGGY / PARTIALLY-RECOVERABLE`
- 当時のサービス案内: `DEPRECATED`
- 神話・人格・物語: 当時の表現を保持
- 現在のQ Atlantis仕様: [工学棚](../engineering/index.md)を参照

旧文書に記載された能力、サービス提供、科学的・医学的・物理的効果が現在も利用可能・検証済みであるとは限りません。この注記は旧世界を否定するためではなく、時代と実装状態を混線させないためのものです。
