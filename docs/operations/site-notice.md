# サイト上の表現と免責

Quantaril Cloud Q Atlantisには、ゲーム世界、神話、宗教・霊的実践、哲学、個人的体験、創作、研究仮説、技術設計、旧サービス資料が含まれます。

このサイトに書かれた内容は、それだけをもって科学的事実、物理的因果、医学的効果、法律判断、犯罪性、特定個人の責任、現在利用可能な製品機能を保証するものではありません。医療・法律・安全に関する現実の判断では、状況に適した専門的な情報と支援を利用してください。

体験、信仰、神話、物語を掲載することは、語り、感じ、解釈し、遊ぶ自由を尊重するためです。掲載はすべての解釈や現実原因をサイト運営者が一律に認定することを意味しません。また、研究・工学上の注記は、神話や信仰を否定・追放するためのものではありません。

`Q3 / SphereOS Memorial`にある旧サービス案内、旧規約、能力記述は、記載当時の資料です。現在の提供状態と実装状態は、[Q Atlantisステータス](../engineering/q-atlantis/status.md)を確認してください。

外部サイト、SNS投稿、旧Custom GPTs等は、提供元の変更・終了により利用できない場合があります。
