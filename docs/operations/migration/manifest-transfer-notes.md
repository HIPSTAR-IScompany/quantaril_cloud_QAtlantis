# ZeroRoomLab-manifestからの転送メモ

作成日: 2026-07-13  
更新日: 2026-07-13

## 受け取った方針

- 生ノートとドラフトはmanifest側で保管し、公開可能な正規化文書をこのサイトへ転送する。
- ハブ文書とストリーム文書を分け、正本本文を複製せず参照する。
- 生成ロジック、配置判断、Docusaurus公開を別工程にする。
- 神話・哲学・人格資料を技術実装へ吸収しない。
- 転送時は原典、抽出範囲、未転送部分、状態を記録する。

## 正本

- [Quantaril Cloud Atlantis世代 文書体系マップ](https://github.com/saitoomituru/ZeroRoomLab-manifest)
- [ZeroRoomLab-manifest](https://github.com/saitoomituru/ZeroRoomLab-manifest)

ローカル開発時の正本候補は、兄弟リポジトリ`ZeroRoomLab-manifest/note/`および`docs/operations/`にあります。公開サイトからローカルファイルへリンクしないため、Web上では正本リポジトリの入口を案内します。

## このサイトの責務

この文書は正本の複製ではなく、Q Atlantisサイトが何を受け取ったかを示す受領票です。具体的な転送状態は`migration/transfer-status.yml`で追跡します。
