# Q3からQ Atlantisへの移行

移行は、旧文書を新しい表現へ一括置換する作業ではありません。

1. 原典と取得元を固定する。
2. 文書を原典・派生・正規化・生成物・旧世代に分類する。
3. 神話、実践、哲学、研究、工学の主棚を決める。
4. 混成文書は原文を残し、必要な断片だけ抽出する。
5. 旧URLと参照元を記録する。
6. 新しい文書をステージングで確認する。
7. 公開後も未転送部分と旧版を辿れるようにする。
