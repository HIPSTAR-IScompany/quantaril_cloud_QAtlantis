# 来歴と正本

## 役割

- **ZeroRoomLab-manifest**: 生ノート、統合ノート、Atlantis設計正本、転送候補。
- **このサイトのdocs**: 公開用に正規化した説明、実装状態、Q3固有資料への案内。
- **sources**: 未加工原典、取得物、燃料、出典情報。
- **blog**: 公開時点の声と時間軸を持つ年代記。
- **Memorial**: 旧サービス・旧仕様・旧人格・事故・当時の規約。

同じ本文を複数箇所で独立管理しません。正本以外は参照元とrevisionを持ち、変更が必要な場合はまず正本を確認します。

## 原典保護

原典の誤字、強い表現、時代依存の主張は、現在の都合だけで黙って修正しません。必要な注釈、反証、現在仕様は別文書として追加し、相互にリンクします。

人格資料では、元の声、価値、関係性、能力記述、禁止事項、記憶参照を保持します。ASTRO fileへの移行は、原典の上書きではなく来歴付きの派生として行います。
