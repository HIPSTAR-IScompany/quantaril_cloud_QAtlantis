# オカルト燃料庫

ここは、ごみ箱でも隔離処分場でもありません。神話、オカルト、陰謀論的ナラティブ、神学、夢、ペイン、断片的な直観などを、急いで肯定・否定・科学化せずに保つための燃料庫です。

素材はここに留まり続けてもかまいません。神話、実践、哲学、研究、工学のいずれかへ渡せる断片が育った場合だけ、原典を保存したままコピーではなく来歴付きの抽出を行います。

## 運用原則

1. 語り手と取得元を記録する。
2. 観測、体験、解釈、伝聞、創作、仮説を可能な範囲で分ける。
3. 不明なものを無理に分類せず`UNKNOWN`で保持する。
4. 特定個人への犯罪断定、医療効果、現実の危険行為は専用の作業台へ分岐する。
5. 分岐後も原典と、転送しなかった部分を残す。

未加工素材は公開文書と混線しないよう、リポジトリ内の`sources/fuel/`で管理します。
