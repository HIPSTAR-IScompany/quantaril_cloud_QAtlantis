## 1. 受け取った方針

このリポジトリでは、ZeroRoomLab-manifest 側で整理された次の運用方針を、実装側でも追跡しやすい形で取り込んでいます。

- ノート・ドラフトは note 側で保管し、正規化済み文書は docs 側へ寄せる
- ハブ文書とストリーム文書を分離し、参照先だけを管理する
- 生成コード・Docusaurus 設定・コンテンツ生成の責務を分ける
