既存IT、人間工学、情報子工学を代理戦争させず、物理・protocol・data・UX・意味・World・Provenanceを
横断してdebugする入口です。

## 貢献できること

- `Q(ψ,∇φ,λ)→result|⊥`で観測器、勾配、目的、接続不能を分ける
- ordinary bug、human-factors pain、compound painを適切な棚へroutingする
- backend stateとWorld内Fact、保存dataと意味・来歴を分ける
- Source、Transformer、output、receipt、反対解釈を追跡する
- 既存ITと専門家を使い、情報子工学だけで全部を解こうとしない

PLI例:

```text
このリポジトリーの情報子工学フルスタック向けチュートリアル開始して。普通のbugから複合painまで順にroutingして。
```
