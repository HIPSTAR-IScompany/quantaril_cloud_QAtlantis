# 巫女・スピリチュアル実践者の入口

霊感の有無を工学者へ証明する入口ではありません。感じたこと、祈り、言霊、場、依代、霊障、妖怪、
ソイヤを、自分の原語のまま記録し、必要な部分を他棚へ渡す入口です。

## 貢献できること

- 感じたズレ、波動、言霊、度し難さを原語で報告する
- どの象徴、TPO、関係、場で変わったかを言語化する
- 意訳で芯が壊れていないかreviewする
- 祭りの開始だけでなく、祀り、奉り、政、後始末を研究する
- 人間工学まで解体できた部分を工学者へ渡す
- 射程外は医療、環境調整、神学、工学等へhandoffする
- 深いWorldを閉じる時の解除、鎮魂、減圧、aftercareを設計する
- `メタい`構造と、自分または共同体の`霊的`Experienceを混線させず両方残す

## この入口が与えないもの

他宗派の教義裁定、医学的診断、無制限の祓いauthority、Git merge権限は与えません。言語化できない部分を
`unknown`として積むことはできますが、不安と唯一解を囲い込む壺ムーブにはしません。
