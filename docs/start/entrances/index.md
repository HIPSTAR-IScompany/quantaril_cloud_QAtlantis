# 読者・参加者別の入口

職種、宗派、persona、プレイスタイルは格付けではありません。同じ構造へ、異なる問いとPresentationから
入るための入口です。

| 入口 | 最初に扱うこと |
|---|---|
| [巫女・スピリチュアル実践者](./spiritual-practitioner.md) | 原語、妖怪、霊障、ソイヤ、まつり、祓い、handoff |
| [神学者・宗教実践者](./theologian.md) | 宗派定規、信仰告白、鎮魂、和解、他Worldへの非越権 |
| [哲学者](./philosopher.md) | 主体、意味、自由、責任、Human-is-the-loop |
| [ゲーマー・playtester](./gamer-playtester.md) | 面白さ、公平、攻略、クソゲーフラグ、cluster差 |
| [工学者](./engineer.md) | state、interface、権限、test、receipt、Meaning Bridge |
| [情報子工学者・フルスタック](./infoton-engineer.md) | IT、人間工学、意味、観測者、複合painの横断 |

## PLIで開始する

Git connectorやrepositoryを読めるAIがある場合、たとえば次のように開始できます。

```text
このリポジトリーの巫女向けチュートリアル開始して
このリポジトリーの神学者向けチュートリアル開始して
このリポジトリーの哲学者向けチュートリアル開始して
このリポジトリーのゲーマー向けSRハンターのチュートリアル開始して
このリポジトリーのサーバーレスエンジニア向けチュートリアル開始して
このリポジトリーの情報子工学フルスタック向けチュートリアル開始して
```

入口の選択だけから、習熟度、信仰、実装意図、Git権限、merge権限を推定しません。既定は読み取り専用の
案内です。Note、Issue、PR、実装へ進む場合は、本人の意図と接続先の権限を確認します。

## 途中で棚を変えてよい

一つの入口に留まる必要はありません。巫女が工学を学んでも、エンジニアが神学を読んでも、ゲーマーが
情報子工学へ入っても構いません。Bridgeを渡っても、元の棚と原語を捨てる必要はありません。
