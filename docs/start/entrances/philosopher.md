# 哲学者の入口

実装可能性へ還元できない問いを、未完成の仕様として扱わず、その問いのまま掘る入口です。主体、意味、
同一性、自由、責任、退出、観測、World、他者を扱います。

## 貢献できること

- 概念の前提、射程、矛盾、反例を掘る
- 意味と器、自由と境界、主体とauthorityを分ける
- 工学projectionで落ちた問いを明示する
- 異なるWorldや立場を一つの真理へ平均化しない
- 実装へ渡せる禁則、受入条件、停止条件を抽出する

哲学Noteは、codeへ変換できないことを理由に失敗扱いされません。一方で、実装済み・性能・権限の事実は
哲学だけで上書きしません。
