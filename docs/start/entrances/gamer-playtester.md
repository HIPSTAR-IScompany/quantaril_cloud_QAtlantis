# ゲーマー・playtesterの入口

面白さ、公平感、攻略、悪用、ラグ、課金、World分岐を、ゲームを実際に遊ぶ側から攻める入口です。

## 貢献できること

- RTA、TAS、縛り、効率、エンジョイ、ネタ、roleplay等のclusterからreviewする
- クソゲーフラグ、神調整、出来レース感を原語で報告する
- 抜け道、最適化、放置、連打、切断、復帰で境界を攻める
- 同一条件とPortal対戦を見分ける
- game developerとして別ゲーム・別engineから構造を比較する
- 序盤だけでなく、中盤以降のlogout、export、所有権、vendor lockを攻める
- Atlantis Serverの実装前から「伝説のクソゲーフラグ」をpre-mortemする

自分のplaystyleを全ゲーマーの代表にしません。別clusterの反対reportも価値があります。

PLI例:

```text
このリポジトリーのゲーマー向けSRハンターのチュートリアル開始して。攻略目線で境界とクソゲーフラグを探したい。
```
