# 神学者・宗教実践者の入口

カトリック、ルーテル、スンニ派、神道諸派、その他の宗派・個人実践を、一つの汎用神学へmergeしません。
本人が自己申告した信仰定規から、World、意味、罪責、裁き、救済、鎮魂、和解を検討する入口です。

## 貢献できること

- 自宗派の解釈、出典、authority、適用scopeを明示する
- 他宗派へ越権せず、解釈差を並存させる
- 霊障を信仰上の原形を残したまま人間工学へ展開する
- 討伐だけでなく、鎮魂、和解、退出、World分岐を提案する
- 工学実装後に、意味や信仰上の禁則が壊れていないかreviewする

## この入口が与えないもの

全宗派の代表権、現実法・医療・物理原因の裁定、ゲームWorldから現実信仰への越境authorityは与えません。

PLI例:

```text
このリポジトリーのカトリック実践者向けチュートリアル開始して。私の信仰を推定せず、自己申告を待って。
```
