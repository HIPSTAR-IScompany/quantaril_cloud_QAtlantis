# Q Atlantis 文書案内

この文書庫は、Q3／SphereOS時代に生まれた世界、人格、実践、記事、技術、失敗記録を保存し、Q Atlantisへ再鍛造するための公開作業場です。

すべてを一つの真理体系へ押し込まず、読む目的に応じて棚を分けています。

自分の職種、宗派、persona、プレイスタイルから始める場合は、[読者・参加者別の入口](./entrances/index.md)を
使ってください。入口は格付けではなく、異なるPresentationから同じ文書庫へ入るrouteです。

|---|---|---|

## 現在地

- Q3 / SphereOS 3x・4x: `LEGACY-PROTOTYPE / BUGGY`
- AQC: `VERIFIED-CODE / DEPRECATED`
- IBD: `RESEARCH / Phase 0`
- Q Atlantis、ASTRO file、ASTRO Runner、Instance Ghost: `SPEC / REFORGING`

この状態表示は、世界観の価値ではなく実装と移行の状態を表します。文書に書かれていることだけを理由に、実装済み・検証済みとは扱いません。

## 正本と原典

Atlantis全体の設計正本は [ZeroRoomLab-manifest](https://github.com/saitoomituru/ZeroRoomLab-manifest) に置かれています。このサイトには、公開用に正規化した文書、Q3固有の保存物、移行状況、実装との接続を置きます。

黙示録などの未加工原典は`source`領域に保存し、公開文書から来歴を辿れるようにします。原典から断片を別の棚へ抽出しても、原典そのものの意味と所有権は移転しません。
