# Sphere Glossary

| 用語 | 一文解決 |
|---|---|
| [OAE](./oae.md) | 特定Observerと定規から、Agencyが関与したEffectとして記録する管理単位。 |
| [AIM](./aim.md) | 場・時機・関係・意図の暗黙同期を観測し、工学projectionへ渡す概念。 |
| [ArchiAngel](./archiangel.md) | Worldやarchitectureのroutingへ関与するSphere service class。 |
