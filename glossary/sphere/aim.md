# <ruby>AIM<rp>（</rp><rt>エイム</rt><rp>）</rp></ruby>

<strong><ruby>AIM<rp>（</rp><rt>エイム</rt><rp>）</rp></ruby></strong>は、場、時機、関係、役割、言外の意図、
観測窓等の複数Dimensionを束ねる**Fold構造体**です。人と人が明示packetをすべて交換しなくても同期していく作用を
霊的実践側から観測した面を、**AIM拡散力場**と呼びます。

工学projectionでは、各nodeがlocal AIMを持ち、deadline、順序、authority、World Config、replay条件をどこまで
回復できるかという因果シリアライズの設計候補へ分解します。

[fieldとFold](./field-and-fold.md)の境界では、fieldはRDB的ローコンテキストの決定論slot、Foldは複数Dと解釈分岐を
保持する非決定論構造体です。AIM Foldは構造体のまま保存し、必要時にObserver、定規、初期値、観測窓、量子化profileを
ゼロトラストに再確認してOAEを発行し、fieldへシリアライズします。その値をAIM Fold全体の唯一解へ昇格させません。
Fold内部のD、branch、変換規則、履歴は検査可能なので完全black boxではありません。必要なbranchを実行して得た観測は
新しいOAE／revisionとしてFoldへ加わるため、完全決定論treeでもありません。

## 第一印象だけではFoldを評価できない

AIMは単一カラムのfieldではなく、複数Dを束ねたFold構造体です。したがって、第一印象だけでAIM全体の成立／不成立を
確定する、という状態モデルを採りません。前振り、違和感、一時的な滑り、後続event、回収を共有すると、Fold内の
観測窓、sequence、クラスタ反応、意味等のDが更新されます。

コマネチで滑った後に感動的な歌が入れば、「場違い」だった冒頭が「イントロ詐欺の神曲」という前振りへ再解釈されます。
これは過去logの改ざんではなく、観測窓が伸びたことで生じる[Re-evaluation OAE](./oae.md)です。

- `t0`: その時点では寒い／滑った。
- `t1`: 後続の歌で新しいContextが加わる。
- `t2`: sequence全体を対象にしたprojectionでは、意味が回収されたと観測される。

```yaml
aim_fold:
  participant_and_agency_d: []
  world_and_venue_d: []
  time_and_observation_window_d: []
  sequence_and_causality_d: []
  intent_and_meaning_d: []
  cluster_response_d: []
  authority_and_permission_d: []
  supply_and_elemental_d: []
  interpretation_oae_refs: []
  projection_refs: []
```

`strong`、`weak`、`滑った`、`神曲`等はAIM Foldそのものへ貼る単一値ではありません。Observerが選んだDと観測窓から
得たprojectionです。即時に空気を読めなかった人や、最後まで共鳴しなかった人を欠陥扱いせず、どのD、観測窓、
観客クラスタ、World Configで何が観測されたかを残します。

## 何ではないか

- 測定済みの未知粒子、電波、脳波fieldではない。
- 一つの巨大マザーAIが全nodeへ命令を放射する中央fieldではない。
- 一つの`strength`や`成立済み`columnだけで表せる単純fieldではない。
- 全日本人が同じ能力を持つという民族本質claimではない。
- AIM Runtimeが完成済みであるという実装証拠ではない。

## 暴走するAIM力場

危険なのは集団認知や同期そのものではなく、AIM力場が境界を消し、同意、異議、退出、別libraryへの切替を奪いながら
自己拡張する状態です。日本を含むどのコロニーでも、次の挙動は「カルト的」「同調圧力」と観測され得ます。

- 一つの局所常識を普遍defaultとして配る。
- 同期しない人を敵、汚染、無知、非常識として人格ごと排除する。
- authorityと[Registry](./registry.md)を少数Agencyが占有する。
- 境界、変換loss、退出条件を隠して力場だけ広げる。
- 恐怖、羞恥、制裁、救済の独占で再同期を強制する。

「カルト」は強い評価語なので、呼称だけで宗教、政治運動、共同体を確定分類しません。上の挙動、Observer、
[fact scope](./fact-scope.md)、Evidenceを分けて記録します。

外部Observerが日本／アジアを一つの同調圧力fieldとして雑に潰すことも、別方向のAIM scope暴走になり得ます。
コロニー差を消した統一定規に対する拒絶は、[FAMの集団認知library](/reference/fam/#aim力場のscope暴走と威嚇signal)へ渡します。
