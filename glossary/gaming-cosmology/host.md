# <ruby>Host<rp>（</rp><rt>ホスト</rt><rp>）</rp></ruby>

**Host**は、[World](./world.md)や[Runner](./runner.md)を収容し、実行資源と境界条件を与える上位環境です。

有限なRunnerがHostの全状態を直接観測できない、というVM／ベアメタルの比喩にも使います。これは物理宇宙がsoftware
simulationであることや、特定宗教の創造神が計算機であることの証明ではありません。

神学Presentationでの「主／絶対Root」と人格的な神格Agencyの区別は、用語をHostへ還元せず文書庫側で扱います。
