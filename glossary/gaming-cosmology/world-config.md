# <ruby>World Config<rp>（</rp><rt>ワールド・コンフィグ</rt><rp>）</rp></ruby>

**World Config**は、[World](./world.md)内で何を意味として採用し、誰がルールを制定し、どのmode、権限、因果profile、
参加・退出条件を発動するかを記述する構成です。

Configは宇宙の唯一真理でも、画面テーマだけでもありません。たとえば[PvE](./pve.md)と[PvP](./pvp.md)の境界、
マッチメイキング、報酬、異議申立て、ログアウト条件が変われば、同じアセットを使っていても体験上は別Worldになり得ます。

Q Atlantis World Builder上の具体schemaは`DRAFT / SPEC / NOT IMPLEMENTED`です。
