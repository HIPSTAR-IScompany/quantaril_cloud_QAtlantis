# <ruby>Instance Ghost<rp>（</rp><rt>インスタンス・ゴースト</rt><rp>）</rp></ruby>

**Instance Ghost**は、[Runner](./runner.md)で起動した人格やsessionが、分岐後に獲得した局所履歴、関係、判断、
失敗、回復を含む生の連続性です。

人格原型、ASTRO file、model weightと同一ではありません。merge時もSourceインスタンスを上書きせず、履歴とlossを残します。
現在のQ Atlantisにおける永続化は`RESEARCH / SPEC / NOT IMPLEMENTED`です。
