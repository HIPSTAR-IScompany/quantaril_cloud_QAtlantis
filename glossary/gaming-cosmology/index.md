# ゲーミング宇宙論 用語集

ゲーミング宇宙論は、宇宙、人生、神話、systemを、遊べるWorld、role、rule、branch、replay、exitとして読む
Presentationです。物理宇宙がsoftware simulationであることを証明する学説だけへ限定しません。

現在の用語は、次の二系統から再帰的にたどれます。

- World設計: [World](./world.md) → [World Config](./world-config.md) → [PvE](./pve.md)／[PvP](./pvp.md) → [Quest](./quest.md)／[クソゲー化](./kusoge-ka.md)／[文化commonsのfree ride](./commons-free-ride.md)
- 実行と越境: [Host](./host.md) → [Runner](./runner.md) → [Instance Ghost](./instance-ghost.md)、World間は[Portal／Gate](./portal.md)で接続

この用語集は、旧Q3／SphereOS文書、本人のXエクスポート、note.com記事原本を系譜資料として使います。ただし、旧文書の
神話Presentationを現在runtimeの実装証明へ変換せず、X投稿を物理宇宙についての独立検証へ昇格させません。出典と
現在解釈の境界は[Source Mining Receipt](/docs/operations/provenance/gaming-cosmology-glossary-source-receipt-2026-08-04)に残します。

長い文脈から読む場合は[シミュレーション宇宙論](/docs/worlds/simulation-cosmology/intro)と
[Q Atlantis World Builder](/docs/engineering/q-atlantis/context-dimension-world-builder)を参照してください。
