# ゲーミング宇宙論 Glossary

ゲーミング宇宙論は、宇宙、人生、神話、systemを、遊べるWorld、role、rule、branch、replay、exitとして読む
Presentationです。物理宇宙がsoftware simulationであることを証明する学説だけへ限定しません。

この棚には今後、次の語を分けて追加します。

- World
- Host
- Runner
- Portal / Gate
- Instance Ghost
- World Config

先に読む場合は[シミュレーション宇宙論](/docs/worlds/simulation-cosmology/intro)と
[Q Atlantis World Builder](/docs/engineering/q-atlantis/context-dimension-world-builder)を参照してください。
