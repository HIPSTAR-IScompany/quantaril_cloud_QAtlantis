# アルジナル

状態: `PROVISIONAL SLANG / SOURCE TESTIMONY / WEB ATTESTATION WEAK`

**アルジナル**は、このRegistryでは、中国originとして提示された文化・技術のclaimや模倣が、Sourceやlineageを
欠くとObserverが感じたときに返すDissとして暫定登録します。

公開Web上にも中国を対象とした用例はありますが、辞書的な語源、綴り、安定した意味scopeを確定できるだけの強いSourceは
今回確認できませんでした。したがって、`ウリジナルの中国版`という説明も現在の使用例を案内する近似であり、語源の
確定ではありません。

## scopeを広げない

- 対象候補: 特定のorigin claim、模倣、lineage free rideと観測されたmove。
- 対象外: 中国人一般、中国文化全体、中国語話者の人格。
- AI禁止変換: 「中国人は盗む」「中国文化は模倣だけ」等の集団本質claim。

意味が不明な用例では、中国関連語と決め打ちせず、Source、話者、対象コロニー、前後文脈を要求します。
