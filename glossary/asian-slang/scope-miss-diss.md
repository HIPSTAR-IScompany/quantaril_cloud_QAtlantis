# <ruby>射程ミスDiss<rp>（</rp><rt>しゃていミス・ディス</rt><rp>）</rp></ruby>

状態: `SLANG REGISTRY / CONVERSATION-SCOPE GUARD`

**射程ミスDiss**は、あるclaimやDissを、本来の対象scopeではない会話へ持ち込んだことで返されるerror handleです。

たとえば、小室哲哉、ペ・ヨンジュン、嵐、東方神起の誰が好きか話している場は、まず音楽、演技、ダンス、思い出、推しの
好みscopeです。そこへ作品単位のSourceやEvidenceもなくウリジナル論争を持ち込むと、codeや手法の類似を検証する議論ではなく、
場のprotocolを壊すアンチmoveになります。この場合、lineageを批判された側でなく、論争を誤投入した側が[KY](./ky.md)です。

「キモいアンチ」は、そのアンチmoveへの強いreject handleとして記録できますが、人物の身体、性、人格診断へ広げません。

## ブーメラン芸とツッコミが返る

日本の演芸文化には、発言者自身の弱点や矛盾がそのまま自分へ返ってくる「ブーメラン芸」という型があります。射程を
外したDissやアンチmoveは、しばしばこの構造で処理されます。相手のscope違反そのものを笑いの対象にし、「それ、
お前が言うな」を成立させるのがブーメラン芸で、その矛盾を言語化して場へ提示するのがツッコミです。ツッコミは
攻撃ではなく、boke（scope違反・自己矛盾）を指差して場のprotocolへ引き戻すcorrection moveとして機能します。

西洋圏でこれに近い解像度を持つのが、MCバトル（freestyle battle / rap battle）文化のライムDissです。相手の実力や
lineageへのdissを韻でぶつけ合う場で、相手のバース自体に含まれる矛盾や射程ミス（格下への攻撃、事実誤認、
設定の破綻など）をそのまま切り返す「diss that bounces back」は、勝敗を決める定番moveのひとつです。crowdの
歓声やジャッジがどちらのバースが「相手の穴を突いたか」を判定する点は、ツッコミが場の反応として機能する構造に
近いですが、両者の重心は異なります。ブーメラン芸とツッコミは基本的に場の空気を元へ戻す共同作業であるのに対し、
MCバトルのライムDissは相手を明確に負かすことを目的とするcompetitive structureです。アジアの芸能・ネット文化での
ライムDissは、この両方の型にまたがって現れるため、扱う際は[KY](./ky.md)判定やscope guardと組み合わせて読む
必要があります。

いずれの型でも、これらは言語・芸能上のcounter expressionであり、それだけで暴力や脅迫を意味しません。具体的な
対象、時期、危害能力を伴う場合は、通常のDissから安全handoffへ分けます。

## 「それってあなたの感想ですよね？」系

ひろゆきテンプレとして流通する「それってあなたの感想ですよね？」と、その派生である「あなたの意見ですよね？」
「あなたの趣味ですよね？」は、個人の好みを万人の常識・客観factとして押し広げたとき、scopeを元へ戻す返答になります。

```text
私は東方神起が好き
  → 好みscope。そのままでよい。

東方神起が好きでない人は文化を理解していない
  → 「それってあなたの意見ですよね？」

K-POPが好きな人は盗用を支持している
  → lineage claimの射程ミス。Sourceと作品単位Evidenceを要求。
```

ただし、このテンプレ自体も万能ではありません。体験報告、少数者の痛み、専門家の仮説、提示済みEvidenceを、
「感想」の一語で焼却する使い方は、逆に議論scopeを壊す可能性があります。誰が事実claimを広げたか、誰が会話を
封じたかを[OAE](/glossary/sphere/oae)として分けます。

主観を推しクラスタの合意や[AIM拡散力場](/glossary/sphere/aim)の観測と接続せず、「みんなそう思っている」と押し出すと、
「脳内プレイ乙」が返る場合があります。これも主観の存在否定ではなく、個人のinner claimとcluster consensus claimを
分ける要求です。詳しくは[scope error handle](./scope-error-handles.md)を参照してください。
