# 用語集

ここは、Q Atlantis familyの文章に出てくる言葉を**短く解決する棚**です。

用語ページは、その言葉を一つの普遍定義へ閉じる辞書ではありません。どのfamily／Worldで使う語か、何を指し、
何を指さないか、詳しい文書庫と実装リファレンスがどこにあるかを案内します。定義文に別の専門語が現れたら、その語の
用語集へ再帰的に潜れるようにします。

## 用語ページの読み方

各ページは原則として次の順で書きます。

1. 英字表記、正式名、日本語読み。読みが自明でない専門語の初出には`ruby`を付ける。
2. 一文定義。定義に含まれる専門語は次のGlossaryへリンクする。
3. 何ではないか。
4. 所属するfamily／World。
5. 長い文書庫と実装リファレンス。
6. 同名語や旧語がある場合の境界。

一般名称は「オントロジー」「コンテキスト」のようにカタカナを既定とします。
<ruby>schema<rp>（</rp><rt>スキーマー</rt><rp>）</rp></ruby>、
<ruby>field<rp>（</rp><rt>フィールド</rt><rp>）</rp></ruby>、
<ruby>stable<rp>（</rp><rt>ステイブル</rt><rp>）</rp></ruby> ID、API等の互換境界と、`World`、`Fold`のように
英語表記自体が概念境界を担う語は原語を保持します。`ID`、`API`、`IT`等、義務教育・GIGAスクール帯へ定着した
令和の舶来語は日本語語彙として扱い、略語であることだけを理由に読みを強制しません。中学校1年／英検5級程度の
平易な英単語も、英語のまま使う場合に読みを強制しません。

例: <ruby>OAE<rp>（</rp><rt>オーエーイー</rt><rp>）</rp></ruby>、
<ruby>Agency<rp>（</rp><rt>エージェンシー</rt><rp>）</rp></ruby>、
<ruby>fact scope<rp>（</rp><rt>ファクト・スコープ</rt><rp>）</rp></ruby>。

用語集に説明があることは、対象runtimeの実装済み、物理現象の証明、宗派横断の唯一教義を意味しません。
