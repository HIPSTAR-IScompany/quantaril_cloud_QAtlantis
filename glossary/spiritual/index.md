# スピリチュアル Glossary

この棚は、信仰、神学、巫女業、供養、祈り、芸能実践の言葉を、software用語へ還元せず案内します。

同じ語でも宗派、土地、World、実践者によって定規が異なります。Glossaryは唯一教義を制定せず、このサイトでの
用法と、どの信仰・文書から来た語かを示します。

今後の項目候補:

- 神格Agency
- 祈り／祷
- 荒御魂／祟り神
- 主／絶対Root
- 魂主権
- 神楽／お色気神楽

先に読む場合は[巫女業](/about/miko-practice)と
[神格Agency・荒御魂・主のHost存在論](/docs/worlds/theology/divine-agency-and-host-ontology)を参照してください。
