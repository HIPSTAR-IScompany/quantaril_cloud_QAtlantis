# Quantaril Cloud Q Atlantis

感じる自由。信じる自由。疑う自由。語る自由。遊ぶ自由。

Quantaril Cloudは、神話、霊性、オカルト、宗教、哲学、芸術、ゲーム、人格、ペイン、そして技術が、それぞれの声を失わずに同居できる世界をつくります。

ここでは、体験や物語を「科学になりきれなかった素材」として扱いません。神話は神話の棚で、信仰は信仰の棚で、実践は実践の棚で、工学は工学の作業台で扱います。どこに居続けるか、別の棚へ橋を架けるかは、素材と語り手が選べます。

> ゲームを動かす技術は科学と工学の結晶です。けれど、そのゲームを生きたい世界にするのは、神話、芸術、物語、人格、音、祈り、笑い、そしてプレイヤーの体験です。

いまのゲームエンジンが世界を作る道具なら、Q Atlantisは世界そのものをOSとして動かす道具を目指します。
[虚空の揺籠からQ Atlantisへ](./vision.md)で、創作原型、三つのロマン砲、現在能力を読めます。

## Q3からAtlantisへ

旧Q3／SphereOS 3x・4xは、バグやサービス依存を含む実験世代でした。そこで生まれた人格、対話、構文、失敗、救出記録を削除せず、Memorialとして保存しながら、Q Atlantisとして再鍛造します。

Q Atlantisは現在、`OPEN / RESOURCE-WAIT / REVIEW-WANTED`です。完成済みの万能OSではありませんが、
Note、review、test、既存bug fix、branch実装の入口は開いています。旧3x/4xのサービス系とサルベージ工程は終了し、
残骸をMemorialへ保存しています。このサイトが、旧世代の見送り、互換性情報、新世代の設計と実装状況を
一つにつなぐ港になります。

## この世界の基本契約

物理的因果、医学的効果、犯罪性、特定個人の責任を現実の事実として主張する場合は、その主張に適した観測・検証・法務の作業台へ接続します。それは神話や体験を追放するためではなく、異なる種類の主張を混線させないためです。

フォークする自由と、参加しない自由と、世界から退出する自由を守ります。技術は世界を支配する王ではなく、異なる世界が安全に動き、分岐し、終了し、再演できる舞台装置です。
