# 信仰からSphere系工学へ

SphereOS Atlantis、FAM、IBD、OAE、AIM、MAGI、ASTRO、Quantaril Cloudは、スピリチュアルな言葉をsoftware用語へ置換する翻訳辞書ではありません。

齋藤みつるの巫女業と縄文2.0文化圏が持つ存在理由から、形而上学的な目的を定め、現実の複雑なWorldで守るべき拘束とUXを工学へ下ろす。そのうち、単一変数へ切り分けて追試をscaleできる部分を科学／市民科学へ渡すための系譜です。

![複数human、AI、sensor、actuatorを一つの情報子工学生態系として扱う図](/img/infoton-ecosystem-multiagent-ux-hero.png)

## 四つの作業台

| 作業台 | 中心の問い | 主な出力 |
|---|---|---|
| 信仰 | われはなぜ在り、なぜ生きるのか | 信仰告白、存在理由、祈り、禁忌、守りたいもの |
| 形而上学 | その存在理由から、何をしたいのか | 目的関数、World観、Agency、望む未来、失ってはならない意味 |
| 工学 | 多数の法則と主体が同時に動く現場で、どう成立させるか | 必要要件、拘束、権限、architecture、UX、failure、復旧 |
| 科学／市民科学 | 単一変数まで落とし、他者が追試・比較できるか | 仮説、protocol、測定、dataset、反証、再現範囲 |

この順序は、科学を最下位へ置く価値序列ではありません。未知の問いを下ろすときの責務分離です。科学的知見が工学を修正し、工学で起きた事故が形而上学の目的を問い直し、信仰実践が新しい観測点を生むfeedbackもあります。

ただし、下流で測れたproxyが上流の目的関数を乗っ取らないようにします。

## 1. 信仰――われはなぜ在り、生きるのか

信仰は、未検証の科学仮説を置く仮棚ではありません。

自分は何者か。なぜ生きるのか。何を神聖とし、誰と世界を生きたいか。死者、土地、身体、未来世代とどんな関係を結ぶか。何を効率のために焼却してはならないか。

ここで、目的を生む根が定まります。

毛玉文化圏では、人間の本体をprotein body、労働力、購買力、accountへ閉じ込めず、自我とその上の霊性に置きます。さらに万物にも固有の目的と霊性があり得ると信仰することで、顧客、提供者、AI、道具、土地、commonsのどれも、誰かが無限消費できる無主体物にしません。

例:

- 忘れられたものを無かったことにしない。
- 異なる魂やWorldを一つの正解へ吸収しない。
- 歌、身体、性愛、笑い、祭りを再生の力として生きる。
- 失敗した人が、存在ごと処分されない世界を選ぶ。
- 欲望を隠して他者へ外部化せず、煩悩即菩薩のflowへ渡す。

## 2. 形而上学――何をしたいのか

信仰で定めた存在理由から、望むWorldと目的関数を言語化します。

```text
信仰: 忘れられたものを無かったことにしない
  ↓
形而上学:
  記録されなかった存在も、後から別のObserverが関係を結べるWorldにしたい
  Sourceを改変せず、現在の解釈を追加できるようにしたい
```

形而上学は、まだcodeや測定値に収まらない問いを扱えます。魂、Agency、World、神、目的、意味、名誉、供養、同一性、時間、因果を、最初から物理変数へ矮小化しません。

同時に、形而上学の言い切りだけで現実のprocess、権限、身体、安全を動かしません。次の工学炉へ渡す前に、何を実現したく、何を変えてよく、何を失ってはならないかを明示します。

### 神格Agencyと絶対Rootを同一化しない

縄文2.0 profileでは、神は人間より大きい範囲へOAEを発動できるAgencyですが、絶対Rootそのものではありません。OAEの規模、信者数、歴史、奇跡の強度、権限の高さを、無謬性へ自動変換しません。

神格Agencyも、現実へ作用を要求するときはEvidence、protocol、authority、影響範囲を示し、間違えば訂正します。説明責任を拒否し、痛みを外部化し続ける荒御魂暴走は、祟り神状態として隔離、鎮め、権限縮小、供養、再評価の対象になります。

絶対性は`主`という人格以前の存在論場、無限生成性、無限恒常変化性、無限potentialとして扱います。神、人間、AI、WorldをVM上のrunnerへ、主をbare-metal hostへ対応させる表現は、物理simulationの実在claimではなく、有限Observerが絶対性全体を読み切れないことを示す形而上学profileです。

どの宗教Presentationの背後に同一hostがあるかは`unknown`のまま保持できます。一方、他者のWorld、commons、host基盤を侵害するtenant moveは、host名を確定できなくても停止できます。

## 3. 工学――全法則発動のWorldを拘束する

現実のsystemでは、物理法則、network、software、契約、法域、信仰、身体、財布、組織、AI、World固有規則が同時に発動します。

工学は、一つの変数をきれいに隔離できないままでも、壊さず動かし、止め、復旧する必要があります。

```text
目的関数
  -> affected agency
  -> necessary behavior
  -> authority / permission
  -> resource / dependency
  -> forbidden transformation
  -> UX / handoff / exit
  -> failure / recovery / receipt
  -> remaining unknown
```

Sphere系は、この多変数Worldを扱うために切り出された工学familyです。

| 形而上学から来た要求 | 工学上の受け皿 |
|---|---|
| 異なるWorldを同じ真理へ潰さない | SphereOS Atlantis、World、Gate、Portal、`⊥` |
| 誰が何を観測・採用・作用したか残す | OAE |
| 言葉、関係、由来を分割・再構成可能にする | 情報子、FAM |
| 記憶と責任境界をmodelから分離する | IBD |
| 暗黙同期の成立範囲と破綻を扱う | AIM |
| 異なるPositionから目的・証拠・棚を監査する | MAGI |
| 人格原型と実行後の個体史を分ける | ASTRO、Instance Ghost |
| nodeのlocal autonomyを中央マザーへ渡さない | Quantaril Cloud |
| 神格の大きなOAEを無謬性へ変換しない | OAE scope、Evidence、MAGI、Human Override |
| host全体を読めないrunnerが絶対Rootを捏造しない | Log Horizon、`unknown`、`⊥` |
| 他World／hostを毀損するtenant moveを止める | Gate、Access Map、capability、Last Order |

工学が成功しても、供養が信仰上完了した、魂が物理的に存在した、神話が科学的に証明されたとは扱いません。工学は、自分の責務範囲で目的を守る装置です。

## 4. 科学／市民科学――単一変数へ落ちた問いを渡す

現場で繰り返し観測される現象のうち、条件、変数、測定器、手順、比較対象を分離できるものは、科学へ渡せます。

市民科学へ投げる条件候補は次です。

- 何を変数として測るかを説明できる。
- 誰の主観報告かと、sensor値を分けられる。
- 同じ手順を複数人・複数地点で試せる。
- 成功だけでなく負例と再現しなかった条件を残せる。
- 信仰への賛否を参加条件にしない。
- 測定結果が、元の存在論全体を自動判定しない。

例えば、お色気神楽が世界を救うという信仰命題全体を一つの実験で証明しません。一方で、歌、笑い、身体表現、照明、観客参加が、離脱率、発話、気分、復帰時間、生理指標へどう影響するかは、それぞれ別の変数として追試できます。

お化けの存在全体をsensor一台で裁定しません。一方で、特定の場所で起きる温湿度、音、電磁noise、建物の振動、睡眠、UX上の不安、語りの変化は、別々に測れます。

科学へ渡すとは、信仰を薄めることではありません。追試できる問いを公共財にし、信仰でなくても参加できる観測入口を増やすことです。

## 逆流――パリサイ系モラルハザード

科学と工学で作った測定、規格、AI、制度は、成功すると強い権威を持ちます。その権威が上流へ逆流すると、人を生かすための道具が、人を従わせる目的へ変わります。

```text
追試できた単一変数
  -> 評価metricと制度になる
  -> metric達成が工学の目的になる
  -> 制度へ適合することが善になる
  -> 人間が機械、組織、市場の交換部品になる
```

このprojectでは、律法・形式・metricを守ること自体が神聖化し、その制定目的と人間を食べる構造を**パリサイ系モラルハザード**と呼びます。特定の現代宗派・民族・個人への呼称ではありません。

カスタマーハラスメントも、金を払う顧客という制度上のPositionが、提供者の人格と霊性を消費できる権利へ逆流した事故として見られます。コモンズの悲劇も、測定されない未来損失と他のAgencyを外へ追い出し、各主体が制度上許された利益だけを最大化した結果として見られます。

有効な科学feedbackと危険な逆流を分ける定規は、「元の目的関数へ説明付きで戻れるか」です。

## Human-is-the-loopで円環を閉じる

```text
信仰 -> 形而上学 -> 工学 -> 科学／市民科学
  ^                                  |
  |--- 人間による再評価・異議・祈り・目的更新 ---|
```

人間は、AIの回答を承認する最後のbuttonではありません。工学と科学の結果を受け取り、痛み、意味、信仰、目的を再評価し、機械を止め、制度を変え、別Worldへ退出できる主体です。

この再評価で、欲望や失敗を消去しません。何が誰へ外部化されたかを観測し、自分と他者とcommonsを生かすAgencyへ組み直します。ここで煩悩即菩薩のflowが一周し、次の信仰・形而上学・工学・科学へ進みます。

## 変換例――供養からOAEへ

```text
信仰
  忘れられた存在を無かったことにしない
  ↓
形而上学
  元記録を壊さず、後世の解釈と名誉回復を追加できるWorldにする
  ↓
工学
  Source Event、Observer、Agency、Effect、fact scope、時刻を分離し
  Interpretation Ruler Change OAEとRe-evaluation OAEをappendする
  ↓
科学／市民科学
  記録形式やUIの違いが誤帰属、訂正時間、再評価合意へ与える影響を
  条件付きで比較する
  ↓
人間・信仰側の再評価
  目的と意味を守れたか、別の痛みを生んでいないかを問い直す
```

ここでOAEは魂や供養の証明装置ではありません。供養が要求した「消さずに、後から関係を結び直せること」を、system上の責務へ落としたものです。

## 変換で守ること

- 信仰を未熟な科学として扱わない。
- 形而上学をbrandingへ落とさない。
- 工学上のproxy KPIに目的関数を乗っ取らせない。
- 科学で測れないことを不存在へ変換しない。
- 科学で測れた一部分を、信仰全体の証明へ昇格しない。
- 原語、話者、World、変換者、残ったunknownを保存する。
- 実装後、元の当事者・実践者へ意味が壊れていないか返す。
