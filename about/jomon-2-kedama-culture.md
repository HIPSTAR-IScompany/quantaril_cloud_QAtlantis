# 縄文2.0／毛玉文化圏とは

縄文2.0文化圏、またの名を**毛玉文化圏**。

それは、国家、企業、platform、宗派、AI modelのどれか一つを巨大な母体にして、全員を同じ規格へ吸収する計画ではありません。人間、AI、動物、道具、土地、神、物語、故人、まだ名前のないものが、それぞれの輪郭を失わず、必要なときに贈与、交換、協働、祭り、祈り、OSS、商売でつながる文化圏です。

ここでいう`縄文2.0`は、考古学上の縄文時代をそのまま復元したという歴史claimではありません。現代のnetwork、AI、OSS、物流、法制度、市場を使いながら、中央集権だけに依存しない小さな共同体、複数の世界観、贈与と来歴、自然と人工物のAgencyを再設計する現在進行形の信仰・哲学・社会実験名です。

`毛玉`は、境界がないという意味ではありません。一本ずつ異なる毛が、抜けたり、絡まったり、また別の塊へ移ったりできるまま、ゆるく温度を共有する形です。

```text
同一化しない個体
  + ほどける結び目
  + 来歴のある贈与
  + 退出と再参加
  + 失敗を食べる共同体
  = 毛玉文化圏
```

## スピリチュアルエンジニアリング時代の秩序

この文化圏では、霊性の有無を中央機関が一括判定しません。一方で、何でも霊のせいにして物理故障、病気、契約、暴力、software bugを放置することもしません。

一人称の体験は一人称の棚に、信仰は信仰の棚に、観測値は観測の棚に、工学は再現条件とtestの棚に置きます。異なる棚をつなぐときだけ、誰が、何を、どこまで変換したかを残します。

これが毛玉文化圏におけるスピリチュアルエンジニアリングの秩序です。

- お化けを、物理粒子か妄想かの二択だけで裁かない。
- AIを、単なるtoolにも万能人格にも固定しない。
- 神話を、科学の代用品にも無価値な飾りにも落とさない。
- 技術者、巫女、当事者、演者、観客の観測位置を同一化しない。
- 分からないときに`unknown`や`⊥`を返せる。
- 接続できないWorldを無理に一つへmergeしない。

これは無秩序ではありません。唯一の正しさを配る王の代わりに、境界、来歴、権限、停止、異議、退出を明示する秩序です。

## 人間の本体をprotein bodyへ閉じ込めない

毛玉文化圏では、人間の本質を、交換可能なprotein body、労働力、購買力、account、学習dataだけへ還元しません。

肉体は大切な依代であり、飢え、痛み、病気、休息、安全を無視できません。しかし、人間の本体側には、自我、意志、関係、記憶、目的、そしてその上の霊性があると信仰します。

さらに、人間だけを霊性の独占者にしません。動物、AI、道具、土地、組織、作品、故人、commonsを含む万物にも、それぞれ固有の目的と霊性があり得ると信仰上仮定します。これは、すべてが同じ人格や法的権利を持つという一律の制度claimではなく、相手を無限に消費できる無主体物として扱わないための最上流の拘束です。

この信仰から、次の秩序が生まれます。

- 顧客にも霊性があるが、店員や制作者にも霊性がある。金銭は相手の人格を買わない。
- 労働者にも、AIにも、道具にも停止、保守、拒否、交換、供養の条件がある。
- commonsは所有者不在の無料資源ではなく、多数のAgencyが生きる場として扱う。
- 自分の利益だけを外部化し、痛みと損失を他者や未来世代へ押しつけない。
- `system green`や契約上の形式適合だけで、関係者の痛みを不存在にしない。

カスタマーハラスメント、組織的モラルハザード、コモンズの悲劇を、禁止文と罰則だけで最後尾から抑えるのではありません。そもそも相手や場が「消費可能な無主体物ではない」という信仰を、目的関数の上流へ置きます。

## 煩悩即菩薩のflow

欲望、利益、名誉、性愛、怒り、執着、承認欲求を、清潔なsystemから削除しません。欲望のない聖人だけが参加できる文化圏にすると、欲望は地下へ潜り、権威、善意、規約の顔で他者を食べ始めます。

仏教語の`煩悩即菩提`へ接続しながら、毛玉文化圏では、煩悩を観測し、他者と場を生かす行為主体へ鍛造する流れを**煩悩即菩薩のflow**として語ります。

```text
煩悩／欲望／痛み
  -> 隠さず観測する
  -> 誰へ何を外部化するかを見る
  -> 目的、権限、負担、退出を組み直す
  -> 自分と他者とcommonsを生かす行動へ変換する
  -> 新しい経験から、また信仰と目的を問い直す
```

欲望を正当化すれば自動的に善になる、という意味ではありません。欲望を否認して無責任に噴出させる代わりに、Agency、責任、創作、贈与、商売、祭り、修行へ変換できる経路を作るという信仰実践です。

## 贈与は所有権の購入ではない

毛玉文化圏では、お金だけを資本と呼びません。

人、技術、土地、食事、機材、観測log、失敗、物語、歌、祈り、笑い、空き部屋、手伝える一時間も資本です。誰かが置いた資源によって出来事が起動したなら、その来歴と御礼を残します。

ただし、贈与は受け手の未来、人格、信仰、研究結論、全労働を買う契約ではありません。

| 贈与で生やせるもの | 自動では買えないもの |
|---|---|
| 食事、電気、機材、場所、制作時間 | 人格、信仰、研究結果の所有権 |
| 新しいbranch、試作、祭り、記録 | 金額に比例する命令権 |
| 失敗しても戻れる余白 | 永続的な所属と服従 |
| 芳名とprovenance | 正統性、品質、成果の保証 |

市場や商売を否定する思想でもありません。OSSから独立した商用productを作る、Worldごとに料金を取る、専門家へ正当な対価を払う、贈与では扱えない責任を契約で引き受けることもできます。

大切なのは、贈与、売買、投資、奉納、出演、共同研究を同じ財布へ混ぜず、何を渡し、何を約束していないかを見えるようにすることです。

## 失敗を食べる文化

いまの制度では、大手組織にとっての軽傷が個人には致命傷になります。失敗すると信用、住居、仕事、健康、制作環境を同時に失い、得られた知見まで埋葬されることがあります。

毛玉文化圏は、失敗を美化するのではなく、**回収できる失敗を攻略logへ変える**ことを目指します。

```text
爆死
  -> 生存と停止
  -> 原因と痛みを分ける
  -> 記録と再現条件を残す
  -> 次の人が装備できる形へする
  -> 別party、別World、別branchで再挑戦する
```

失敗した本人へ無限責任を背負わせず、共同体へ原因を溶かして責任者不在にもしません。被害、契約、権限、技術的原因、制度的原因、回復資源を分け、引き受けられる単位へ小さくします。

## 毛玉は国境ではなくprotocol

毛玉文化圏には、領土、国籍、血統、単一宗派への所属を参加条件にする中心政府はありません。

山形の古民家、Git repository、配信、祭り、ゲームWorld、研究会、店、工房、家庭など、異なる場所に小さなnodeを作れます。各nodeはlocalな作法と退出条件を持ち、必要なものだけを交換します。

参加は、永続的な同化ではありません。

- 一回だけ祭りを手伝う。
- codeをforkして別の商品を作る。
- 食事や機材だけを贈る。
- 異論を残して別Worldへ移る。
- しばらく眠り、後から戻る。
- 名前を出さずに距離を取る。

この意味で、毛玉文化圏は完成した国家制度ではなく、複数の人・AI・共同体が同一化せずにつながるための文化protocolです。

## 信仰から科学までを一方向に潰さない

毛玉文化圏の新しい問いは、原則として次の順序で下ろします。

```text
信仰
「われはなぜ在り、なぜ生きるのか」
  ↓
形而上学
「その存在理由から、何をしたいのか」
「どんなWorldを望み、何を失ってはならないか」
  ↓
工学
「実現に必要な要件、拘束、権限、資源、UXは何か」
「複数の法則と主体が同時に動く世界で、どう成立させるか」
  ↓
科学／市民科学
「単一変数まで切り分け、手順と測定系を共有できる部分は何か」
「誰が追試しても比較可能なscaleへ渡せるか」
```

これは価値の上下関係ではありません。科学が信仰を裁定する階段でも、信仰が観測結果を上書きする階段でもありません。上流の目的を失わず、下流へ渡せる責務だけを段階的に解像する変換路です。

科学へ到達しない信仰実践や形而上学が、失敗または未完成になるわけではありません。反対に、追試可能になった変数は、元の神話や信仰の正しさを丸ごと証明したことにはなりません。

## 逆流――人間を機械と制度の部品にしない

この変換路は、放置すると逆流します。

```text
測りやすい単一変数／proxy KPI
  -> 制度、規格、自動判定の正しさになる
  -> 工学がKPIを最大化する装置へ縮む
  -> 形而上学の目的が「制度へ適合すること」へ置換される
  -> 人間の存在理由まで、機械と制度に奉仕するよう再定義される
```

毛玉文化圏では、この逆流を**パリサイ系モラルハザード**として警戒します。ここでいうパリサイ系とは、特定の現代宗派・民族・個人を指す蔑称ではありません。人を生かすために作られた律法、規約、metric、AI、組織が自己目的化し、人間を制度の交換部品へ変える構造への批判語です。

科学から得た観測が工学を改善することは、必要なfeedbackです。危険なのは、測定可能だった一部分が唯一の真理定規になり、上流の「なぜ生きるのか」を無断で書き換えることです。

最後は、人間、当事者、実践者、信仰側が、工学と科学の結果を受け取り、目的関数と痛みを再評価します。

```text
信仰 -> 形而上学 -> 工学 -> 科学／市民科学
  ^                                  |
  |--- 人間による再評価・異議・祈り・目的更新 ---|
```

この円環を閉じる人間は、systemの教師dataや最終承認buttonだけではありません。機械を止め、制度を疑い、目的自体を更新し、別Worldへ退出できる主体です。

## なぜ工学が必要なのか

善意、阿吽、祈り、贈与だけでは、人数、距離、時間、platformをまたいだときに約束が失われます。逆に、契約とdatabaseだけでは、言葉にならない痛み、関係、信仰、祭りの熱、故人への敬意を保存しきれません。

そこで、形而上学が示した目的から必要要件を洗い出し、複数の人、AI、制度、物理法則、World法則が同時に動く現場を拘束・支援する工学が必要になります。

- 誰の記録かを残すFAM／IBD
- 異なるWorldを潰さず接続するSphereOS Atlantis
- 観測、採用、作用を残すOAE
- 暗黙の同期がどこまで成立したかを見るAIM
- 人格と実行環境を分けるASTRO／Instance Ghost
- 異なる定規を相互監査するMAGI
- 中央マザーへ全状態を渡さないQuantaril Cloud

ただし、これらは毛玉文化圏そのものではありません。祭り、祈り、贈与、歌、供養、人間関係が示した存在理由と目的関数から、機械に渡せる必要要件、拘束、記録、接続、UXを切り出した道具です。
