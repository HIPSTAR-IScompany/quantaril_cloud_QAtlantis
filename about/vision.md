# 虚空の揺籠からQ Atlantisへ

このページは、[縄文2.0／毛玉文化圏](./jomon-2-kedama-culture.md)と[齋藤みつるの巫女業](./miko-practice.md)から、機械へ渡せる責務を切り出した工学visionです。文化圏や信仰全体をQ Atlantisへ還元するものではありません。

Q AtlantisはWorldコンテンツの束ではなく、人格、記憶、道具、AI、社会ルール、現実の機器までを、
それぞれの境界と主権を保ちながら一つのWorldの出来事として扱えるようにする分散メタエンジンの
公開研究・開発プロジェクトです。

その原型は、2008〜2015年頃の創作『虚空のインフェルニティ』に登場したメタエンジン
「虚空の揺籠」にあります。これは現実の実装実績ではありません。しかし、人格を持つ世界、運営後の独裁、
分断、移住、出口、インフラ依存まで、コードを書く前に長期の物語として負荷試験した創作上の設計資産です。

## 三つのロマン砲

### 世界を生やす

ゲーム、神話、宗教、研究、組織ごとに、意味Kernel、因果、権限、表現を持つWorldをつくる。
すべてを一枚のグローバルWorldへ塗り潰さず、必要ならPortal、Gate、Converterで接続します。

### 個体を持ち運ぶ

ASTRO package、Instance Ghost、FAM、IBD/IFDの候補を使い、AI人格やAgentを一つのSaaS、model、端末へ
閉じ込めない。copyだけで同一性や同意が成立したことにせず、系譜、権限、欠損、分岐を表示します。

### 現実へ門を開く

既存のPOSIX OS、database、IAM、API、server、game engine、deviceを置き換えるのではなく、Atlantis Server
Advanced等のGate候補から接続する。基幹をAtlantisへ強制移住させず、必要なWorldだけに門を開きます。

### Cloudを分散処理へ戻す

各nodeはlocal clock、local state、local AIM、owner authorityを持ちます。Quantaril Cloudは全状態を中央マザーへ
吸い上げず、Fold7G、Gate、Portalの接続候補を通じて、必要な因果、権限、receiptだけをP2P／E2Eで交換します。
Infernity系Gaming Worldや今後のWorld templateは、この基盤を試すreference Worldであり、基盤の本体ではありません。

## ロマンと実装状態を同じ箱へ入れない

架空MMOのseed engineや、異なるゲーム世界をcharacter converterで渡る物語は、ゲーマーへ届く強い比喩です。
一方で、特定作品との提携、公式互換、完成済みのVR MMOを意味しません。

創作、信仰、ゲームExperienceは実装証拠ではありません。しかし、工学がまだ名前を持たない事故、退出不能、
意味drift、クソゲーフラグを先に見つけるdebuggerです。工学はそれを薄めず、仕様、test、Portal、Exit Contractへ
鍛造します。

## 現在地

旧SphereOS 3x/4xのサービス系は終了し、サルベージ工程を終えました。残骸は消さず、再稼働させず、Memorialへ
保存しています。現在のAtlantisは`OPEN / RESOURCE-WAIT / REVIEW-WANTED`です。Prompt Engineering Editionと
開発足場はありますが、standalone runner、production edge distribution、Fold runtimeは完成していません。

## 非公式な比喩について

本文中の既存ゲーム・製品への言及は、構造を説明するための非公式な比較です。各権利者による承認、提携、
互換性保証を示しません。Q Atlantisの価値は比喩の権威ではなく、公開仕様、code、Issue、Note、reviewで検証します。
